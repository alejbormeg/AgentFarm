# M1-003 — Java y control plane Mateu

Petición: migrar todo a Java/Spring Boot, usar Mateu para gobernar nodos,
trabajadores, tareas, estados y progreso; trabajar en Ubuntu 24.04 LTS WSL.
Instalación principal Docker Compose, JAR alternativo.

1. Retirar el runtime Python y portar coordinador, alcance y presupuesto.
2. Mantener invariantes e importar SQLite sin pérdida de hashes, estados,
   consumos ni reservas; rechazar conflictos transaccionalmente.
3. Panel Mateu auténtico, seis vistas con datos persistentes y sin actividad ficticia.
4. Nodos/Boxer, caducidad, habilitación, asignación con reserva, pausa y cancelación.
5. Autenticación local, protección de acciones y auditoría sin secretos en Git.
6. Compose de un comando con volumen; JAR sin Node/Python.
7. Pruebas de invariantes, importación, concurrencia y HTTP. Comprobar JAR,
   contenedor e interfaz en WSL.
8. Explicar instalación, migración y límites de esta versión.

No incluye ejecutar proveedores, leer cuotas automáticamente, matar procesos,
aceptar implementaciones ni consenso entre nodos.
