1. Herramientas y permisos

En Linux o WSL necesitas Java 21+, Git, GitHub CLI y Codex autenticados.

gh auth status · codex login status

El trabajador todavía comparte la identidad Linux del servicio. Este asistente no acredita aislamiento de credenciales.

2. Credencial del nodo

Este panel aún no tiene nodo o cuenta. AgentFarm puede crear un nodo con sus dos trabajadores y una cuenta de suscripción Codex que para al 98 % de uso semanal.

Guárdala en AGENTFARM_STATE/node-token con permiso 600. No la pegues en comandos con historial ni en Git.
