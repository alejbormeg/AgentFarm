# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Java 21, Spring Boot 4, Mateu. Requested by the project owner. Ubuntu 24.04 LTS WSL development.
## Users
The project owner governs a development agent team and reviews its evidence.
## Product Purpose
Know active nodes and Boxer workers, tasks, reported progress, and govern scope, budget and acceptance.
## Operating Context
Docker Compose is the confirmed primary installation; executable JAR is the alternative.
## Capabilities and Constraints
Port simulator, commit scope gate and API/subscription budget ledger. Preserve existing SQLite data.
Real provider execution and automatic quota telemetry remain unimplemented.
## Brand Commitments
AgentFarm: Boxer workers, Napoleon/Snowball direction. Human acceptance; 50% weekly quota example.
## Product Principles
Reported progress is distinct from verified implementation. Unknown nodes are not active.
Governance changes are audited. No automatic merge or paid fallback.
